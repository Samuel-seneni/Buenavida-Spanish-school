# Buenavida Spanish School

A responsive website for Buenavida Spanish School, designed to introduce the school, showcase Spanish courses, share learning resources, and help students enroll.

## Features
- Home and About pages
- Spanish courses from A1 to C2
- Online admissions with WhatsApp integration
- Blog and testimonials
- Contact page
- Responsive navigation and footer

## Technologies
- React
- Vite
- Tailwind CSS
- React Router
- Lucide React
- React Icons

## Installation

```bash
npm install
npm run dev
```

Open the local URL displayed in your terminal to view the website.

## Build for Production

```bash
npm run build
```
